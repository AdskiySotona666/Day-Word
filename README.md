# Слово Дня

## Описание

«Слово Дня» — мобильная игра-головоломка на угадывание слова, вдохновлённая популярными играми жанра word-guessing, но реализованная с собственной механикой, визуальным стилем и набором функций.

Каждый день пользователю предлагается новое слово из тематической категории (например, страны, кино, музыка — набор категорий расширяемый). Игроку даётся ограниченное число попыток угадать слово; после каждой попытки приложение подсвечивает буквы в зависимости от того, угадана ли буква и стоит ли она на правильном месте.

Дополнительные функции:
- Тематические категории слов вместо случайного словаря
- Локальная статистика: текущий и лучший стрик, количество побед, распределение попыток по раундам
- Шеринг результата раунда в виде эмодзи-сетки (без раскрытия самого слова) через стандартный Android Share Intent
- Анимация переворота плиток при вводе и проверке буквы
- Собственная цветовая палитра и оформление, не заимствованные у существующих аналогов

## Технологический стек

| Компонент | Технология |
|---|---|
| Язык | Kotlin |
| Среда разработки | Android Studio |
| UI | Jetpack Compose |
| Архитектура | MVVM (ViewModel + StateFlow) |
| Локальное хранилище | Room / DataStore (статистика, история игр) |
| Асинхронность | Kotlin Coroutines |
| Шеринг результата | Android Share Intent (ACTION_SEND) |

## Отличия от аналогов (во избежание нарушения авторских прав)

- Собственное название, цветовая палитра, шрифты и анимации
- Тематические (категорийные) слова вместо произвольного словаря без категорий
- Дополнительная игровая механика

## Планируемая структура проекта

Проект будет построен как стандартное Android-приложение на Jetpack Compose. Ожидаемая структура модуля `app`:

```
app/src/main/java/com/example/dayword/
├── data/          # Room, DataStore, репозитории
├── domain/        # модели и игровая логика
├── ui/            # Compose-экраны, ViewModel, темы
└── core/          # вспомогательные утилиты, константы
```

(Структура будет уточнена после добавления кода — сейчас репозиторий содержит только это описание.)

## Запуск проекта

Требования:

- Android Studio (последняя стабильная версия)
- JDK 17+
- Android SDK
- Устройство или эмулятор с Android 7.0 (API 24) или выше

Шаги:

1. Склонировать репозиторий: `git clone <url-репозитория>`
2. Открыть проект в Android Studio: `File → Open` → выбрать папку проекта
3. Дождаться синхронизации Gradle (пункт меню `File → Sync Project with Gradle Files`)
4. Запустить приложение на устройстве или эмуляторе (кнопка Run / `Shift+F10`)
